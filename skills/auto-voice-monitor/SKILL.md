# Auto Voice Monitor

1. 先读 `config.json` 的品牌/车系范围；不要把聚合品牌与子品牌重复配置。所有运行命令见 `README.md`，数据库契约见 `docs/schema.md`。
2. 首次运行小批量 `sync` 并核对原帖 URL、文本与错误日志；随后生成一次 `baseline`。只有基线成功生成后才开始 `daily`。
3. 日报只使用成功抓取后入库的评论，检查 `run_log` 和最新扫描时间。采集失败不能解释成没有用户反馈。
4. 链接取 `showId`/原始 URL，不把 `Koubeiid` 评论编号拼入 URL。发表时间与本地采集时间分开。
5. 自动规则是候选过滤；交付重要问题前人工复核原文、年款/版本、场景与重复性。不得从单例推断故障率。
6. 报告默认保留在本地，不自动公开或发给第三方；通知接收者与投递方式由部署者授权配置。
